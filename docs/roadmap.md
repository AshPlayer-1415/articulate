# Articulate roadmap

This describes direction, not release dates or a promise that every preview is
already available. Suggestions are welcome in [Ideas](https://github.com/AshPlayer-1415/articulate/discussions/categories/ideas).

## Available: the local pilot

`articulate-local@0.0.1`, selected with `@pilot`, includes local CLI/MCP setup,
reviewed preferences, scoped profiles, per-agent sharing and versioned shortcuts.
See [profiles](work-modes.md), [connections](agents.md) and [release notes](releases/0.0.1.md).
The package works without an Articulate account. Model behavior and usefulness
still need checking on the person's actual task.

## In development

- A clearer profile-building experience with editable preferences and named styles.
- Portable, inspectable context and more explicit active-profile feedback.
- Optional account sign-in and onboarding, shown as preview screens on the website.
- Better separation of a person's working preferences and the relevant project knowledge.

## Planned exploration

- User-approved profile refinement from real corrections and work patterns.
- Optional project-knowledge connections with source references and clear scope.
- Additional agent adapters validated on their native hosts.
- Cloud services for ambitious projects and organization-scale setups.

Private/public data boundaries, user review and factual fidelity remain part of
every milestone. Cloud workspace availability and additional integrations will be
announced when there is a released, verified experience to try.
