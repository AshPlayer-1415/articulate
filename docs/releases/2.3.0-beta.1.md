# 2.3.0-beta.1 — profiles and versioned shortcuts

Status: verified testing candidate, held from npm publication at the owner’s
explicit request on 2026-11-01. The published alpha
channel remains 2.2.0-alpha.7. [Native CI for this candidate passed](https://github.com/AshPlayer-1415/articulate/actions/runs/41286674147)
on all nine OS/Node combinations. The earlier alpha.8 CI is separate.

- Named project/task profiles with aliases, immutable revisions, scoped analysis
  and individually approved client grants. General remains a separate profile.
- Explicit request/chat selection; a revoked or deleted selection fails closed.
- Versioned procedures such as SR4@1, aliases, structured required inputs, optional
  exact project-version labels and reviewed documentation freshness checks.
- Bounded context/cache reuse with permission rechecks; resumable profile-specific
  model windows; deletion of one profile or all managed Articulate data.
- Interactive CLI menus, local browser approval and a self-contained setup guide.

Read [the profile and shortcut guide](../work-modes.md) before migration. Update
all connected servers first: creating the first profile upgrades storage to schema
2, which older binaries refuse. No automatic live-profile migration is performed.

Local validation on macOS arm64 / Node 24.22.2:

- 246 source tests passed on each of Node 22.23.4, 24.22.2 and 26.13.0.
  TypeScript checks and the product smoke passed.
- Installed seven-file package: 9 existing distribution checks and 11 profile/
  shortcut checks passed. Four SDK stdio connections exercise distinct client
  configurations, not four native agent GUI installations.
- The published alpha.7 server refused the new schema in a synthetic fixture and
  preserved the profile. No real profile was used.

The passing native matrix ran Linux, macOS and Windows on Node 22.23.4,
24.22.2 and 26.13.0. Windows Server coverage does not certify every Windows desktop
or agent GUI. Actual Cursor discovery and synthetic hosted-model checks are
reported separately from SDK tests. No claim of factual accuracy gains or durable
human preference accuracy follows from these engineering tests.

No unattended publication, telemetry, raw-history sharing or cloud service added.
