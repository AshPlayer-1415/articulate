# Articulate 0.0.1 pilot

This pilot packages the profiles and versioned shortcuts from 2.3.0-beta.1
under the version chosen for the first friend test. Use a supported patched
Node.js release. The first supported patches are 22.23.4, 24.22.2 and 26.13.0.

Published on 2026-11-06 under the `pilot` tag. The canonical build and all nine
native OS and Node.js jobs passed. Fresh anonymous npm installation, the direct
npx command, profiles and shortcuts passed against the published archive.
[Verification receipt](0.0.1-verification.json)
[Native verification](https://github.com/AshPlayer-1415/articulate/actions/runs/42185188318)

Have your coding agent handle the terminal steps with the copy-paste prompt.
[Agent-led pilot guide](../agent-pilot.md)

Open a test project folder and run these commands.

```sh
npm i -g articulate-local@pilot
articulate
```

1. Choose one project and review the suggested preferences. You can add
   preferences yourself if the project has little local agent history.
2. Finish the connection in the wizard or run `articulate connect`. The pilot
   asks before writing settings for all four hosts. Select only the agent you
   want to test for sharing, approve its local page, then reload and open a
   new chat in the project.
3. Ask the agent to check Articulate's status and use your reviewed debugging
   preferences for the project. The expected bundle version is 0.0.1.
4. To test profiles and shortcuts, run `articulate modes` and follow the guide.
   [Profiles and shortcuts](../work-modes.md)

On Windows, PowerShell users who encounter a script-policy error can run
`npm.cmd` and `articulate.cmd`. Claude Desktop may need the local extension
generated by Connect. [Agent setup](../agents.md)

For a one-time launch, run `npx articulate-local@pilot`. The tag currently selects
0.0.1. For repeat testing against this exact build, install `articulate-local@0.0.1`.
