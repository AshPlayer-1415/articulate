# 2.2.0-alpha.5 source proposal

Local CLI and MCP candidate for reviewed collaboration preferences, scoped
activity coverage, per-client consent, refresh guidance and optional descriptive
activity counts. History inference and compatible-model processing are
experimental. No hosted service or enterprise/education outcome claim is made.

This is an unpublished source proposal. Package/registry/container publication,
public repository visibility, release assets and source transfer each remain
subject to the release review. The optional web prototype, internal reports and
private development history are excluded.
