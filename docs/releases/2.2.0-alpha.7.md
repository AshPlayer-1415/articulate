# 2.2.0-alpha.7

Generated connections now bind both local data-directory selectors, preventing a
leftover extension environment variable from redirecting a host to another
instance. Malformed host configuration and profile/session JSON produce controlled
errors without echoing their contents; corrupt local files are left intact.

Adds installation regressions and packaged runtime resilience checks for several
live clients, instance/project separation, live revocation, crash/reconnect,
relocation and corrupt storage. Native CI also checks a pinned Cursor CLI's MCP
initialization/tool discovery without account credentials or model calls.

See [compatibility and scope](../compatibility-and-scope.md) for acceptance checks,
non-goals and unverified combinations. Read the actual final CI results before
calling this build verified. Real desktop UI and model behavior remain separate
checks. No repository visibility, registry publication or efficacy claim is made
by this release preparation.
