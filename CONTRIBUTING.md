# Contributing

This source candidate is an alpha. Run `npm ci --ignore-scripts --no-audit
--no-fund`, `npm run check`, `npm test` and `npm run build` before proposing a
change. Use synthetic fixtures and temporary data directories. Do not import real
agent activity into a test or commit generated profiles, credentials or reports.

Describe the concrete problem, before/after behavior and relevant verification.
Keep current user instructions above stored preferences. Historical records and
model outputs are untrusted data, and no inferred preference becomes active
without human review. Preserve failures and uncertainty in evaluation results.

When a public issue tracker is available, ordinary bugs should include OS, Node,
Articulate and agent versions, the command, expected behavior and actual error.
Inspect any excerpt before sharing it. See SECURITY.md for sensitive reports.
Submissions are intended under the project's Apache-2.0 license; do not submit
material you lack permission to contribute. No claim of contributor ownership
verification or enterprise certification is made by this draft.
