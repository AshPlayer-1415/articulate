# Get help with Articulate

Start with the [setup docs](https://ashplayer-1415.github.io/articulate/docs/)
and [visual walkthrough](https://ashplayer-1415.github.io/articulate/how-it-works/).
The walkthrough labels account-connected preview features separately from the
current npm pilot.

| Need | Where to go |
| --- | --- |
| Installation or usage question | [Q&A](https://github.com/AshPlayer-1415/articulate/discussions/categories/q-a) |
| Product suggestion | [Ideas](https://github.com/AshPlayer-1415/articulate/discussions/categories/ideas) |
| A workflow that helped | [Show and tell](https://github.com/AshPlayer-1415/articulate/discussions/categories/show-and-tell) |
| Reproducible bug / pilot feedback | [Issue forms](https://github.com/AshPlayer-1415/articulate/issues/new/choose) |
| Suspected vulnerability | [Private report](https://github.com/AshPlayer-1415/articulate/security/advisories/new) |

Include versions, operating system, the step you tried and the result. Share a
small synthetic reproduction where possible. Leave credentials, login links,
profile exports, activity databases and private conversations out of public posts.
