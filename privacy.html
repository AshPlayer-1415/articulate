Privacy notes.

This public website explains Articulate. It does not run the product or access your local activity.

Updated November 15, 2026

This website

The site contains public presentation files. It has no sign-in form, account tokens, analytics scripts, advertising trackers, history scanner or product backend. Its example preferences are illustrative and are not a real person’s data.

The site is served by GitHub Pages. GitHub records visitor IP addresses for security purposes. See the GitHub Pages data collection note and GitHub Privacy Statement. Links to npm, i-ops and email services are handled by those providers when you use them.

The copy button writes only the displayed installation command to your clipboard when you click it. The example task buttons change illustrative text on this page. This website does not upload your clipboard or make account-service requests.

The local Articulate pilot

Installing the package does not itself approve an activity scan or an agent connection. Guided setup asks you to choose a scope. Supported local activity is processed on your device; cloud-only or deleted history may be unavailable.

Selected imported text is screened for known credential patterns and normally expires locally after 30 days. Screening cannot recognize every secret. Reviewed preferences and other saved profile data remain until you change or remove them.

Raw imported history is not returned through Articulate’s MCP tools. An AI provider can process the reviewed summaries and preferences you approve for its connection. Local analysis and provider processing are separate.

Use articulate privacy to inspect storage and managed-data removal options, or articulate disconnect to remove selected connections. Uninstalling the CLI does not automatically erase saved profiles. Articulate erasure does not delete original agent histories, exports you saved elsewhere or copies held by other providers.

Account and early-tester testing

Account onboarding is being tested separately from this website and is not required in the published CLI pilot. The account service uses Supabase for sign-in identity, contact/provider profile, session and security records. The application account record holds an opaque user ID, creation date, latest sign-in date and free-plan status.

If you explicitly join the early-tester cohort, a server-dated enrollment is saved so a future announced benefit can recognize that account. Enrollment does not start a paid trial, make a purchase or subscribe you to marketing emails. No Pro benefit has been announced.

A minimal use-report database contract is prepared for account-linked app surface, version, first reported activity and most recent reported day. CLI/plugin reporting is not enabled in the published pilot. Account sign-in does not authorize uploading chats, prompts, project paths, local profiles or device fingerprints.

Deleting a test account removes its application account, early-tester enrollment and use-summary records. It does not remove local profiles, uninstall a plugin or erase every provider log or backup. Managed service logs and backups follow provider retention. See Supabase’s privacy policy. A public account launch and any future data-practice changes will need updated notices.

Feedback and questions

Email hello@i-ops.dev for privacy questions, account help or pilot feedback. Your email service and ours process the message. Please avoid sending credentials, raw chat histories or private project files; describe the issue and redact identifying details.
